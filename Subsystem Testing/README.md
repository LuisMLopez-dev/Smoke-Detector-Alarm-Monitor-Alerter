## Overview
The files contained in this subfolder, Subsystem Testing, are several microcontroller sketches of the individual subsystems of our devices. 
The listener unit and the alarm units' sketches were broken down into their key tasks, and then made into their individual sketches so that we can test them.
Each sub-folder and file is appropriately named for what the sketch is for. Within each sketch is a comment block breaking down several key areas of that sketch.

### Notes on Comments
This includes the name of the test, the purpose of the test, the method of testing, the expected results, and possibly some added notes as well. These serve to explain what the purpose is of that sketch as well as that subsystem itself.
There are few comments on the the individual lines of code themselves because these files are just for testing and the code in them came from the sketches of the devices.
These files are not meant to be a breakdown of the subsystems of the sketches of the devices to understand what they do, but rather just a way to isolate and run those segments. The sketches for the devices themselves are well documented and have line-by-line breakdowns for those who are interested in taking a deeper dive at the structure of the code itself.
